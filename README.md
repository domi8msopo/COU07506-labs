# COU 07506 — Digital Signal Processing Laboratory

## Overview
This repository contains laboratory exercises, Python implementations, experiments, and practical activities completed for the **COU 07506 Digital Signal Processing (DSP)** course.

The laboratory work focuses on understanding digital signal processing concepts through programming, signal analysis, visualization, and practical experimentation using Python.

## Objectives
- Understand the fundamental concepts of Digital Signal Processing.
- Generate and analyze discrete-time signals.
- Apply Python libraries to signal processing tasks.
- Visualize signals using graphical plots.
- Work with digital audio signals, including recording, reading, plotting, and playback.
- Develop practical programming and technical problem-solving skills.

## Tools and Technologies
- **Python 3**
- **Jupyter Notebook**
- **NumPy** — numerical computations and signal generation.
- **Matplotlib** — signal visualization and plotting.
- **SciPy** — scientific computing and signal processing.
- **Git & GitHub** — version control and laboratory work management.
- **GNU Octave** — optional numerical computing environment.

## Laboratory Activities

### Week 1 — Setting Up the DSP Laboratory
- Introduction to Digital Signal Processing and its role in AI.
- Generating discrete-time signals.
- Plotting the unit impulse, unit step, ramp, and exponential signals.
- Exploring exponential signals with different parameter values.
- Comparing discrete-time cosine signals.
- Recording, reading, plotting, and listening to audio signals.
- Initializing and managing a Git repository.

## How to Use This Repository

1. Clone the repository to your computer.
2. Open the project using Jupyter Notebook or JupyterLab.
3. Navigate to the relevant weekly folder.
4. Open the notebook (`.ipynb` file).
5. Run the code cells sequentially to reproduce the experiments.
